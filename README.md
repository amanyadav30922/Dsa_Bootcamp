# Array.cpp - DSA Questions Collection

This repository contains various Data Structures and Algorithms (DSA) questions implemented in C++.
The problems mainly focus on Arrays, Matrices, Strings, and basic problem-solving techniques.

---

# 📚 Questions Included


1. Find all vowels in a String
2. Count consonants in a String
3. Difference between first and last element of array
4. Delete an element from array
5. Find smallest and largest element in array
6. Prefix Sum Array & Range Sum Query
7. Leaders in Array
8. Longest Consecutive Increasing Subarray
9. Frequency Sort
10. Sort 0s, 1s and 2s in an Array
11. Count candidates with more than n/4 votes
12. Insert row/column in matrix
13. Insert/Delete operation in matrix
14. Matrix transpose
15. Transpose of matrix
16. Sum of matrix elements
17. Spiral Traversal of Matrix
18. Matrix Diagonal Difference
19. Rotate Matrix by 180°
